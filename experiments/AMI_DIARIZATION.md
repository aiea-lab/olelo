# AMI Speaker Diarization

## 1. Overview

This experiment performs speaker diarization on the AMI Meeting Corpus using the pretrained **pyannote.audio speaker-diarization-3.1** pipeline.

Speaker diarization identifies **who spoke when** in an audio recording. It divides the recording into speaker-specific time intervals and assigns anonymous speaker IDs (e.g., `SPEAKER_00`, `SPEAKER_01`).

The diarization output will later be combined with Faster-Whisper transcription results to generate speaker-attributed meeting transcripts.

## 4. Diarization Process

The pretrained pyannote pipeline processes the audio and generates speaker-specific time intervals.

The general workflow is:

1. Load the AMI Mix-Headset audio recording.
2. Load the pretrained `pyannote/speaker-diarization-3.1` pipeline.
3. Run speaker diarization on the audio.
4. Identify speaker turns and their corresponding start and end timestamps.
5. Assign anonymous speaker IDs.
6. Export the diarization results in JSON and RTTM formats.

Example speaker IDs:

```text
SPEAKER_00
SPEAKER_01
SPEAKER_02
SPEAKER_03
```

These IDs represent distinct detected speakers and do not identify the actual participants.

### JSON Format

The JSON output contains:

- Meeting ID
- Diarization model
- Number of detected speakers
- Speaker IDs
- Speaker segments
- Start and end timestamps
- Segment durations

Example:

```json
{
  "start": 16.028,
  "end": 23.571,
  "duration": 7.543,
  "speaker": "SPEAKER_02"
}
```

### RTTM Format

RTTM (Rich Transcription Time Marked) is a standard format for representing speaker diarization results.

Each entry contains information about a speaker's speech interval, including its start time, duration, and speaker ID.

Example:

```text
SPEAKER EN2003a.Mix-Headset 1 16.028 7.543 <NA> <NA> SPEAKER_02 <NA> <NA>
```

RTTM files can also be used for diarization evaluation, including Diarization Error Rate (DER) calculations.

To inspect the JSON structure:

```bash

import json

path = "/data/ami-results/diarization/EN2003a.json"

with open(path) as f:
    data = json.load(f)

print("Meeting:", data["meeting_id"])
print("Model:", data["model"])
print("Detected speakers:", data["num_speakers"])
print("Total segments:", len(data["segments"]))

print("\nFirst 5 segments:")
for segment in data["segments"][:5]:
    print(segment)
PY
```

## 8. Next Step: Transcript Alignment

The diarization output identifies speaker turns but does not contain the spoken words.

The Faster-Whisper transcription pipeline independently generates text segments with timestamps.

The next stage combines both outputs:

```text
AMI Audio
    |
    |--------------------------|
    |                          |
Speaker Diarization        Transcription
(pyannote.audio)           (Faster-Whisper)
    |                          |
Speaker IDs                Text + Timestamps
    |                          |
    |--------------------------|
               |
        Transcript Alignment
               |
     Speaker-attributed Transcript
```
